# Security policy

## Supported versions

Only the latest released version of `skpod` receives security fixes.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use **Report a vulnerability** on the repository's Security tab to open a
private report. Include the affected version, impact, reproduction steps, and
any suggested mitigation. If private reporting is unavailable, contact the
repository owner through their GitHub profile to request a private channel
before sharing sensitive details.

You should receive an acknowledgment within seven days. Confirmed issues will
be coordinated privately until a fix and disclosure plan are ready.
